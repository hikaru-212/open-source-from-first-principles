# Repository Licensing Map

[← Back to Project README](README.md)

**Open Source from First Principles** applies separate licenses according to the role of the content:

```text
software and substantial standalone executable content → Apache License 2.0
documentation, prose, and educational materials         → CC BY 4.0
```

## Software and Substantial Executable Content

The [Apache License, Version 2.0](LICENSE) applies to software and substantial standalone executable content, including:

- substantial standalone executable examples under `examples/**`;
- implementation code, executable scripts, tests, or fixtures added in the future;
- equivalent implementation-oriented or executable content wherever it appears in the repository.

## Documentation and Educational Materials

Unless otherwise noted, documentation, prose, and educational materials are licensed under the [Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/) (CC BY 4.0). This includes:

- the root `README.md` and `README.zh-TW.md` files;
- `docs/**`;
- prose documentation, teaching and research notes, Checkpoints, and Deep Dive material;
- diagrams created specifically for the educational material;
- other repository content whose primary role is documentation, guidance, or explanation.

CC BY 4.0 permits sharing and adaptation, including commercial use, with appropriate attribution and an indication of changes where applicable.

A suggested attribution is:

```text
"Open Source from First Principles" by Yen-Hua Chen.
Licensed under CC BY 4.0.
Original source: https://github.com/hikaru-212/open-source-from-first-principles
```

This wording is suggested attribution, not an additional license condition.

## Third-Party Materials

Third-party references, linked resources, quoted materials, and upstream project content remain subject to their respective original licenses and copyright terms.

Unless otherwise noted, CC BY 4.0 applies only to the original educational content created for this repository. Linking to or referencing third-party material does not relicense that material under CC BY 4.0.

第三方引用、連結內容、引述資料與上游專案內容，仍適用其各自原始的授權與著作權條款。

除非另有標示，本 repository 的 CC BY 4.0 僅適用於本專案原創的教材內容；對第三方資料的引用或連結，不代表將該資料重新授權為 CC BY 4.0。

## Illustrative Snippets in Documentation

Ordinary short illustrative code snippets embedded inside CC BY 4.0 Markdown remain part of the CC BY 4.0 document. This repository does not attempt line-by-line dual licensing of those snippets.

Substantial standalone executable examples are Apache-2.0 content even when Markdown accompanies or explains them. The content's primary role, rather than its file extension alone, determines the licensing boundary.
